# 泰國新廠設備追蹤

追蹤泰國新廠每一台設備的待辦、交機、調機和文件。手機和電腦都能用。

- **網頁**：GitHub Pages（這個 repo 的 `index.html`）
- **資料**：你的 Google 試算表「泰國建廠設備追蹤資料庫」
- **檔案**：你的 Google 雲端硬碟「泰國建廠設備文件 / 部門 / 設備名稱」
- **後端**：Google Apps Script（`apps-script/Code.gs`），負責登入、存資料、上傳到雲端硬碟

> 設備清單（含廠商、價格）**不放在 GitHub**，因為這個 repo 是公開的。初始資料在另外提供的 `Seed.gs`，只貼進 Apps Script。

## 功能

| 區塊 | 內容 |
|---|---|
| 總覽 | 全部 / 未開始 / 進行中 / 已完成 / 逾期未交機 / 30 天內交機，點一下就篩選 |
| 部門進度 | 工程一部、工程二部、品保部、製造部、包材、廠務，各自完成率 |
| 模糊搜尋 | 只打部分字、字順不對、打錯一兩個字、簡體繁體混打都找得到（例：「热像」→ 紅外熱像儀、「水份測定」→ 水分測定儀）；可用空白分隔多個關鍵字；找不到時會列出「你要找的是不是」 |
| 清單 | 依部門 / 狀態 / 採購來源篩選，依編號 / 交機日 / 調機日 / 進度排序 |
| 甘特圖 | 下單→交機、預計交機、實際交機、調機期間、今天線；日 / 週 / 月縮放 |
| 匯出 Excel | 依目前篩選匯出甘特圖 `.xlsx`，同時存一份到雲端硬碟「甘特圖匯出」 |
| 待辦事項 | 每台設備預設 11 步（詢價→驗收），可增刪；可用 ▲▼ 或拖曳調整順序；勾選即存檔並記錄日期 |
| 設備欄位 | 名稱、部門、站別、規格、數量、廠商、採購來源、幣別、單價、總價、付款狀態、負責人、下單日、預計 / 實際交機日、調機開始 / 完成日、BOI 狀態、HS Code、原產國、尺寸、水電氣需求、備註 |
| 上傳檔案 | 拖曳或點選，自動放進雲端硬碟「泰國建廠設備文件 / 部門 / 設備名稱」 |
| 登入 | 第一次輸入的帳號密碼就是永久帳密；連續錯 5 次鎖 10 分鐘 |

## 安裝步驟（約 10 分鐘）

1. 用要存資料的 Google 帳號打開 <https://script.google.com>，按 **新專案**，左上角改名為「泰國設備追蹤」。
2. 把 `apps-script/Code.gs` 全部內容貼到編輯器裡的 `程式碼.gs`（覆蓋原本內容）。
3. 左邊「檔案」旁按 **＋ → 指令碼**，命名 `Seed`，貼上另外提供的 `Seed.gs` 全部內容。按 💾 儲存。
4. 右上 **部署 → 新增部署作業**，齒輪選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按 **部署**，依畫面授權（出現「Google 尚未驗證」時按 **進階 → 前往「泰國設備追蹤」→ 允許**）。
5. 複製部署後的 **網頁應用程式網址**（結尾是 `/exec`）。
6. 在 GitHub 打開 `config.js` → 鉛筆圖示編輯 → 把網址貼進 `window.API_URL = '...'` → **Commit changes**。
7. 約 1 分鐘後打開 <https://jimmyeyes.com/TT/>，第一次會要求建立帳號密碼。第一次載入會建立試算表、資料夾並匯入 228 項設備，約 10–30 秒。

## 常見問題

- **試算表已經建立，想把簡體資料換成繁體？** 把 Apps Script 的 `Seed.gs` 換成繁體版、`程式碼.gs` 換成最新的 `apps-script/Code.gs`，儲存後在上方函式選 `convertToTraditional` → 執行。網頁上改過的設備不會被覆蓋，雲端資料夾也會一起改名。

- **修改了 Code.gs 沒生效？** 部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署。網址不變。
- **忘記密碼 / 要重設帳密？** Apps Script 編輯器上方函式選 `resetAccount` → 執行，然後重新打開網頁設定新帳密。
- **檔案太大？** 網頁單檔上限 25 MB。更大的檔案請按「開啟雲端資料夾」直接拖進去。
- **刪除設備會刪檔案嗎？** 不會。只刪試算表那一列，雲端資料夾和檔案保留。刪除單一附件會移到雲端硬碟垃圾桶（30 天內可還原）。
- **同名設備的資料夾？** 同部門有多台同名設備（例如多台防爆櫃）時，資料夾名稱會加上編號，例如 `防爆櫃_E056`。
- **可以直接改試算表嗎？** 可以。網頁每次載入都讀試算表。不要改第一列標題，也不要改 `待辦清單(JSON)`、`附件(JSON)` 欄的格式。
